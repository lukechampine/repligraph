repligraph
----------

A repligraph is an artifact provably produced by a particular mind.

See the [website](https://lukechampine.com/repligraphs) to learn more about what
repligraphs are, how they work, and their various applications.

## How to use this

Paste this into your agent of choice:

> Help me record and verify a repligraph using this repository. Read its documentation and code, determine what I already have available, and walk me through the remaining setup and a small example.
> https://github.com/lukechampine/repligraphs
